# Como Começar?

## Sobre o projeto

O Como Começar? é um sistema web criado durante a
Maratona DevImpacto para auxiliar jovens estudantes
a encontrar cursos gratuitos de tecnologia.

## Problema

Jovens interessados em tecnologia podem ter dificuldade
para identificar cursos adequados ao seu perfil, devido
à quantidade de oportunidades disponíveis em diferentes
plataformas e aos diferentes requisitos de cada curso.

## Solução

O sistema utiliza idade, escolaridade e carga horária
desejada para filtrar cursos cadastrados e apresentar
opções compatíveis ao usuário.
